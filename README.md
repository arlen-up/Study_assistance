# LSSA (Study Overflow) — LMS 학습 도우미 & 커리어 나비게이터

> **미루는 습관, 파편화된 학사 정보, 그리고 단기 기억에 머무는 학습 해결**

학교 LMS(코스모스)와 학사정보를 AI가 읽고, 학생이 **챗봇 하나로** 오늘 할 일·교안 내용·졸업 계획까지 해결하게 돕는 웹 서비스예요.
해커톤 「내 전공 현장을 바꾸는 AI」 출품작 · 🌐 **https://lms-study-helper.vercel.app**

## 🎯 해결하는 문제

| 문제 | 학생이 겪는 장면 | LSSA의 해결 | 확인 방법 |
|---|---|---|---|
| ⏰ **미루는 습관** | 마감을 놓치고, 복습은 "나중에" 하다 잊어버림 | 하루 한 번 **가장 급한 일 하나만** 알림(마감 임박 → 오늘 복습 → 연속 학습 위기) · 연속 학습에 따라 자라는 **펫(알→애벌레→번데기→나비)** · 학습 잔디 | 시연 계정 5개가 펫 단계별로 준비됨, 퀴즈 1개로 진화 |
| 🧩 **파편화된 학사 정보** | 과제는 LMS, 성적·졸업 요건은 학사정보, 교안은 파일 — 여기저기 찾아다님 | 질문 종류를 AI가 먼저 나누고(일상/학습/학적) **알맞은 시스템을 대신 조회**. "졸업까지 몇 학점?", "저번주 자바 내용"을 한 창에서 | [AI 평가](docs/AI_평가.md): 분류·학적 사실 정확도 |
| 🧠 **단기 기억에 머무는 학습** | 읽고 나면 금방 잊음, 어디서 본 내용인지도 모름 | 교안 근거 답변(**[1] 출처 + 쪽·위치**) · 3분 요약 · 슬라이드 퀴즈 · 망각 곡선(1·3·7일) 복습 · 기말 예상 문제 | [AI 평가](docs/AI_평가.md): 맞는 교안 인용·근거 부족 판단 |

## 🤖 AI를 어떻게 쓰나요

- **질문 분류기(Router)**: AI가 일상(chat) / 학습(study) / 학적(info)을 먼저 판단 → 종류마다 다른 도구·답변 규칙 (AI 실패 시 낱말 규칙)
- **RAG + 출처**: pgvector 의미 검색으로 **내 교안**에서 근거를 찾고 `[1]`로 인용, 쪽·소제목 위치까지 표시. 교안에 없으면 지어내지 않고 **근거 부족**
- **MCP 도구 9개**: AI가 교안 검색·과목/주차 찾기·성적표·졸업 요건·과제·진로 분석 도구를 **스스로 골라** 사용. 화면에서 도구 입력/출력을 눌러 확인
- **계산은 파이썬, 조언은 AI**: 졸업 학점·추천 후보는 코드가 정확히 계산하고, AI는 후보 안에서만 골라 이유를 설명 (후보 밖 과목은 자동 제거)
- **구조화 출력**: 요약·퀴즈·예상 문제·마인드맵을 정해진 형식(Pydantic)으로 받아 검증
- **안전장치**: 교안 속 지시문은 따르지 않음(프롬프트 인젝션 방어), 도구는 로그인한 학생 본인 데이터에만 접근

## 🔐 보안 · 확장성

- **학교 계정 연결 = OAuth 2.0 + PKCE**: 학생이 학교에 **직접 로그인·동의**해야 그 학생 전용 토큰 발급. 학교 비밀번호는 LSSA가 받지 않고, 토큰은 암호화 저장·권한 범위·연결 해제 시 폐기
- **계정별 데이터 분리**: 교안·학습 기록·사용자 이름이 계정마다 따로 (DB 검색 함수·RLS까지 소유자 조건)
- **실제 학교로 옮기기**: 코스모스가 Moodle 기반이라 **Moodle Web Services 규격** 그대로 구현 → 학교 앱 등록 후 **주소와 앱 정보만 교체** ([연동 설계](docs/연동_설계.md))

2. 🎓 **학점·진로 → 🏫 학교 계정으로 연결** → 가상 코스모스 화면에서 **시연용 학생 계정 만들기** → 로그인·허용
3. 💬 챗봇에 "졸업까지 몇 학점 남았어?", "남은 과제 알려줘" 질문 · 📤 교안을 올리고 "이 교안 핵심 알려줘"

## 주요 기능

- **챗봇 (메인 화면)**: 질문 종류를 먼저 나누는 Router(💬 일상 / 📚 학습 / 🎓 학적) → 종류에 맞는 MCP 도구로 답변
  - 학습 질문: 교안을 찾아 `[1]` 번호로 인용하고, 밑에 **출처(쪽·소제목 위치)**와 근거 충분/일부/부족 표시 ("저번주 자바 내용 알려줘"도 학기 주차로 계산)
  - 학적 질문: 성적표·졸업 요건·과제를 학교 시스템에서 확인 / 일상 대화: 근거 표시 없이 바로 대답
  - 마크다운 답변, ERD·흐름도·마인드맵은 **그림(mermaid)**으로 표시, 사용한 MCP 도구는 눌러서 **입력/출력** 확인
  - 답변 밑 단추: ⏱ 3분 요약 · 🧠 퀴즈·카드 · 🗺 그림으로 정리 · 📄 교안 보기
- **교안 뷰어**: 챗봇 옆 빈 공간에 출처 교안을 띄움 (PDF는 해당 쪽으로, 글 교안은 답변에 쓴 부분을 노란색으로)
- **퀴즈·카드 · 기말 예상 문제**: 한 번에 한 문제씩 푸는 슬라이드 퀴즈(바로 채점·해설), 문항 수를 정해 만드는 서술형 예상 문제와 AI 채점
- **📊 대시보드**: 연속 학습·이번 주 학습·정답률·오늘 복습 + 주간 학습/정답률/과목별 그래프, 복습 카드(과목·회차·다음 복습일)
- **복습 알림 · 학습 잔디**: 에빙하우스 망각 곡선(1·3·7일), GitHub식 1년 히트맵
- **학교 계정 연결 (가상 코스모스)**: OAuth 2.0 + PKCE로 학생이 직접 로그인·동의 → Moodle 4.5 Web Services 규격으로 과제·마감·강의 자료·성적
- **알림 · 가상 펫**: 매일 저녁 하루 한 번 마감·복습 알림 (맥·윈도우 안내 + 기기에서 바로 확인, 메일 미리보기·카카오톡은 추가 개발 예정), 연속 학습에 따라 자라는 펫
- **계정별 분리 · 사용자 이름**: 교안·학습 기록이 계정마다 따로, 처음 들어오면 겹치지 않는 사용자 이름 정하기
- **시연 계정 5개**: 1~4학년, 수강 과목·학점·과제·관심 직무가 다르고 펫 단계(알·애벌레·번데기·나비)도 다름 (`scripts/seed_demo_accounts.py`)
- **커리어 나비게이터**: 졸업 요건 분석 + 관심 직무별 다음 학기 과목 추천 ("계산은 파이썬, 조언은 AI")

자세한 진행 기록은 [`docs/진행상황.md`](docs/진행상황.md)를 보세요.

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 화면 | FastAPI + Jinja2 템플릿 + HTMX + 순수 CSS |
| API | FastAPI, Pydantic |
| AI | LangChain + MCP Python SDK, OpenAI GPT (`gpt-6-luna`, `text-embedding-3-small`) |
| DB·로그인 | Supabase (PostgreSQL, pgvector, Auth) |
| LMS 연동 | Moodle Web Services REST (코스모스 = Moodle 기반) |
| 배포 | GitHub + Vercel (Python 서버리스 함수, Cron) |

## 로컬 실행

```bash
cp .env.example .env.local          # 값 채우기 (Git에 올라가지 않음)
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn api.index:app --reload --port 8000
python -m pytest -q tests          # 챗봇 마무리 처리·마크다운 안전성 테스트
```

## 진짜 코스모스로 전환하려면 (학교 허가 후)

지금도 학생이 학교에 직접 로그인·동의해야 학생 전용 토큰이 발급되는 구조(OAuth 2.0 + PKCE)라, 바꿀 것이 적어요.

1. 학교 전산팀에 앱 등록 → `client_id`·`client_secret`·돌아올 주소 발급 (OAuth 2.0, 또는 LTI 1.3)
2. `MOODLE_BASE_URL`, `LMS_OAUTH_CLIENT_ID`, `LMS_OAUTH_CLIENT_SECRET`을 학교 값으로 변경
3. 자세한 흐름·막은 공격·확인 기록: [`docs/연동_설계.md`](docs/연동_설계.md)

졸업 요건·전체 성적표는 LMS가 아니라 학사정보시스템에 있으므로 별도 협의가 필요합니다.
