# LSSA 발표 대본 (3분) + 질의응답 대비 (2분)

## 발표 대본 (약 3분)

**[0:00~0:30] 문제와 고객**
저희는 IT계열 학생이 흔히 겪는 세 가지 어려움을 줄이고자 LSSA를 만들었습니다. 복습을 미루는 습관, 학사 정보가 흩어져 있는 문제, 배운 내용을 금방 잊는 문제입니다. 대상은 IT계열 재학생입니다.

**[0:30~1:00] 해결 방식과 전공 연결**
LSSA는 RAG 기반 학습 챗봇과 커리어 나비게이터입니다. 실제 전공 과목 교안을 소재로 씁니다. 화면 오른쪽이 교안 뷰어의 최근 교안 목록입니다. 과목명과 주차로 찾고, 이수 구조로 학점을 계산합니다.

**[1:00~1:40] 시연**
질문하면 교안을 찾아 출처 페이지와 함께 답합니다. 기말 예상 문제는 직접 답을 쓰면 뜻이 맞는지 AI가 채점하고, 정답은 채점 뒤에 보입니다.

**[1:40~2:20] 기술과 AI 기능**
교안을 조각내서 검색하고, 찾은 조각만 근거로 답합니다. MCP 도구 9개로 성적표와 과제를 조회합니다. 로고는 틸론 GPU 환경에서 SDXL-Turbo로 만들었고, 답변 AI는 외부 OpenAI API를 씁니다.

**[2:20~3:00] 한계와 다음 단계**
학사 정보는 모의 시스템이고, 효과는 아직 측정하지 않았습니다. 다음에는 실제 LMS 연동과 다른 학과 교안 확대를 계획하고 있습니다.

---

## 질의응답 대비 (2분 안에 답할 질문)

1. **누가 얼마나 쓰나요? 효과는요?**
   - 답변: 아직 사용자 설문과 효과 측정은 하지 않았습니다. 현재는 시연 계정으로 기능을 확인한 단계입니다.
2. **학사 정보가 실제 학교 시스템과 연결되나요?**
   - 답변: 아니요. 모의 LMS(가상 코스모스)입니다. 실제 연동은 학교 승인이 필요해서 다음 단계입니다.
3. **AI가 틀린 답을 하면 어떻게 하나요?**
   - 답변: 찾은 교안 조각만 근거로 답하고 출처 페이지를 붙입니다. 교안에서 찾지 못하면 '근거 부족'으로 표시합니다.
4. **정답이 미리 보이지 않나요?**
   - 답변: 정답은 서버에만 있고, 답을 제출한 뒤에 채점 결과와 함께 보입니다. 기말 예상 문제는 '정답'이라고 요청할 때만 함께 보여 줍니다.
5. **교내 GPU는 어디에 썼나요?**
   - 답변: 로고 이미지 생성에만 틸론 GPU(SDXL-Turbo)를 썼습니다. 답변 AI는 외부 OpenAI API를 씁니다. 생성 노트북과 설정은 GitHub docs/gpu에 있습니다.
6. **보안은 괜찮나요?**
   - 답변: 로그인 쿠키는 자바스크립트가 읽지 못하게 했고, 학생 데이터는 본인만 조회합니다. 과거 API 키 노출 이력이 있어 재발급을 마쳤고, 그 사실을 진행 기록에 적어 두었습니다.
7. **다른 학과에도 쓸 수 있나요?**
   - 답변: 같은 방식으로 교안을 올리면 됩니다. 실제 확장은 아직 검증하지 않았습니다.
