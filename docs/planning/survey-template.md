# 문제 정의 조사 설문 (5명 이상, 간단히)

목적: "학생들이 복습을 얼마나 미루는지, 학사 정보를 어떻게 찾는지"를 실제 응답으로 확인합니다.
규칙: 응답은 있는 그대로 적고, 숫자는 실제 응답만 씁니다. 표본이 작다는 점은 발표에서 그대로 말합니다.

## 질문 (4개)
1. 수업을 들은 뒤 복습을 언제 하나요? (바로 / 당일 저녁 / 시험 직전 / 거의 안 함)
2. 최근 한 달 동안 복습을 미룬 적이 몇 번 있나요? (0번 / 1~2번 / 3번 이상)
3. 수강 과목, 학점, 과제 마감일을 한눈에 보려면 어디를 확인하나요? (여러 답 가능: LMS / 포털 / 메모 / 기억 / 기타)
4. 가장 불편한 점을 한 문장으로 적어 주세요.
